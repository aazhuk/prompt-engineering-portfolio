## 📊 Детализация документов

### 1. `ab_test_report.md`

Полный отчёт A/B-теста: параметры, результаты по 11 критериям, ключевые находки, рекомендации по применению техник.

**Что показывает:** умение измерять качество промптов и делать выводы на основе данных.

---

### 2. `prompt_evolution.md`

Эволюция промптов от версии А (базовая) до версии В (CoT): структура, дефекты, исправления.

**Что показывает:** итеративный подход, умение улучшать промпты на основе анализа ошибок.

---

### 3. `error_reports.md`

Отчёты об ошибках AI (E-01 – E-10): тип ошибки, причина, способ исправления в промпте.

**Что показывает:** системный подход к диагностике и устранению ошибок.

| ID | Тип ошибки | Способ исправления |
|----|-----------|---------------------|
| E-01 | Нарушение тона | Усилить запреты |
| E-02 | Выдуманные цифры | Только типовые метрики |
| E-03 | Отсутствие структуры | Требовать таблицы |
| E-04 | Несоответствие роли | Чётко прописать роль |
| E-05 | Общие фразы | Требовать механики |
| E-06 | Прямые продажи | Добавить запрет |
| E-07 | Повторение из промпта | Уменьшить контекст |
| E-08 | Нет привязки к площадкам | Требовать привязку |
| E-09 | Нарушение формата таблиц | Унифицировать колонки |
| E-10 | Нет обоснования | Требовать обоснование |

---

### 4. `test_dataset.md`

Тестовый датасет из 30 примеров: 10 обычных, 10 сложных, 10 пограничных. Для каждого — входной запрос, ожидаемый ответ, критерии оценки.

**Что показывает:** глубину проработки, понимание edge cases, готовность к тестированию.

---

### 5. `prompt_templates.md`

Шаблоны под типовые задачи:

- **Шаблон 1.** Экспертная статья для TenChat.
- **Шаблон 2.** Конкурентный анализ (Few-Shot).
- **Шаблон 3.** Анализ сайта (Chain of Thought).

Плюс таблица ограничений (запрет хайпа, эмодзи, выдуманных цифр, прямых продаж).

**Что показывает:** умение создавать переиспользуемые артефакты.

---

### 6. `prompt_documentation.md`

Пример документации промпта для статьи в TenChat: роль, контекст, формат вывода, few-shot, edge cases, обработка ошибок, правила безопасности.

**Что показывает:** готовность работать в команде — документация помогает коллегам быстро разобраться.

---

### 7. `mini_library.md`

Мини-библиотека из 10 промптов:

1. Исследование агентства
2. Анализ ЦА (Zero-Shot)
3. Анализ конкурентов (Few-Shot)
4. Анализ позиционирования
5. Контент-матрица
6. Креативные концепции
7. Визуальная концепция
8. Стратегия развития
9. Критическая оценка
10. Статья для TenChat (CoT)

**Что показывает:** широту экспертизы, готовность покрыть весь цикл маркетинга.
